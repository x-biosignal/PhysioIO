# Version of the available Python mne module

Version of the available Python mne module

## Usage

``` r
pyMNEVersion()
```

## Value

The `mne.__version__` string, or `NA_character_` when mne is not
available.

## See also

[`hasMNE()`](https://x-biosignal.github.io/PhysioIO/reference/hasMNE.md)

## Examples

``` r
pyMNEVersion()
#> [1] NA
```
