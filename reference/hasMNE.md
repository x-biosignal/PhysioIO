# Is the Python mne module available?

Is the Python mne module available?

## Usage

``` r
hasMNE()
```

## Value

`TRUE` if reticulate and the Python `mne` module are both available,
otherwise `FALSE`.

## See also

[`pyMNEVersion()`](https://x-biosignal.github.io/PhysioIO/reference/pyMNEVersion.md),
[`toMNE()`](https://x-biosignal.github.io/PhysioIO/reference/toMNE.md),
[`fromMNE()`](https://x-biosignal.github.io/PhysioIO/reference/fromMNE.md)

## Examples

``` r
hasMNE()
#> [1] FALSE
```
